# Automated entries into RORALGS table
- Python script to create SQL insert statement to add new RORALGS entries
- Written 11/7/2025 by Justin DeKock dekock@slu.edu

## IMPORTANT: DO NOT CHANGE THE NAMES OF ANY COLUMNS IN THE EXCEL SHEET
- the script relies on the names of these columns - they match up to the names of the RORALGS fields in the Banner databse
- changing the names or order of any of these fields will break the script
